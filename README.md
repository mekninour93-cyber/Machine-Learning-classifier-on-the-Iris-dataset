# Iris Dataset ML Classification

This project contains a **Machine Learning classification** of the Iris dataset using Python.  
It includes:
- Loading and exploring the dataset with **pandas**
- Preprocessing and scaling features
- Training a **Logistic Regression** model
- Evaluating performance with **accuracy, classification report, and confusion matrix**
- Visualizing results using **seaborn** and **matplotlib**

## Files
- `iris_analysis.ipynb — ML code
- `iris.txt` — dataset
